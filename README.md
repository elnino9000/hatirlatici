# Hatırlatıcı
Türkçe cümleyle ("yarın 15:00 toplantı") ya da mikrofonla hatırlatma ekler; alarm çalar, bildirim gönderir. Notlar bölümü ve iki ana ekran widget'ı vardır.

- Yedek: ana ekrandaki bulut simgesinden hatırlatma ve notları kopyalayıp yedekleyebilir, panodan geri yükleyebilirsin.
- Tek dosya `main.dart` + `android_ekler/` (widget kodları). Derleme GitHub Actions'ta yapılır.

APK: Releases > "Hatırlatıcı (son sürüm)" > hatirlatici.apk
